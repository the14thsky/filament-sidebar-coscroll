# Changelog

All notable changes to `filament-sidebar-coscroll` will be documented in this file.

## 1.0.0 - Unreleased

- Initial release: the panel sidebar co-scrolls with the page on desktop and in the open mobile drawer, with `topbarOffset()` and `mobileDrawer()` options.
- Works with every Filament sidebar layout: a sidebar collapsed to icons co-scrolls too, while top navigation and a closed fully collapsible sidebar keep Filament's own off-screen sidebar, with no empty column left behind.
